# 环保管理平台 · 二污普系数计算

React + TypeScript + Vite + Ant Design 前端，接入 tool 模块的六个真实接口。

## 本地运行

使用 Node.js 22.12+，推荐 Node.js 22 LTS。

```sh
npm install
cp .env.example .env.local
npm run dev
```

默认进入 `/calculations`。可在 `.env.local` 配置 `VITE_API_BASE_URL`，修改后重启 Vite。开发和预览通过同源 `/api` 转发到该地址，当前按后端免鉴权约定调用。

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

## 结构

- `src/api` 维护请求、响应类型和六个接口。
- `src/features/calculations` 包含列表、计算表单、系数检索、参数与结果展示。
- `src/hooks/useRemote.ts` 管理查询取消、过期响应及重试。
- `src/styles.css` 实现设计稿的布局和响应式适配。

## 生产部署

发布 `dist`，将前端路由回退到 `index.html`。浏览器请求使用 `/api/tool/...`，生产网关必须移除 `/api` 前缀，再转发至后端 `/tool/...`。`VITE_API_BASE_URL` 用于本地代理配置和错误信息，静态产物的生产转发地址由网关配置。后端地址变更后，生产环境需要同步更新网关。

## 首版兼容约定

- 行业、产品、工艺、原料使用可搜索下拉框。打开时请求基础库选项，接口契约见 [tool 模块缺失接口清单](./tool模块缺失接口清单.md)。行业选择后启用工艺，行业与工艺选定后启用产品、原料，上游变化清空下游条件。
- 空项目名称提交“未命名计算”。同一系数记录跨页去重，编辑参数后需要重新试算。
- S/A 直接提交用户输入值，按系数来源填写口径。系数单位缺失时显示“单位未提供”。
- 所有计算与舍入修正使用服务端返回值。已完成记录只读，复制后重新计算再保存。
- 保存失败会保留表单。网络或服务异常时保存结果可能未确认，先从列表核对，避免重复新建。
